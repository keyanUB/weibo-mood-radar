# 周/月统计方法

## 目标

每周总结热门微博对应的事件及高赞评论情绪；每月按自然月重新聚合。没有日情绪分析、日报命令或日报输出。

采样粒度仍为每天：30 条热门微博，每条最多 100 条高赞评论。完整一周目标为 210 条微博采样记录、21,000 条评论采样记录；这些是去重前上限，报告同时展示去重后的数量。

## 时间与去重

所有窗口采用北京时间，开始时刻包含、结束时刻不包含。周报用 ISO 周号命名，月报用 YYYY-MM 命名。`as_of` 表示截止日 00:00，不包含当天，避免把正在采样的一天当成完整天。

归属日期是采样日期。上月发布的微博在本周进入热门榜，其本周评论快照进入本周统计。同一评论在周/月窗口内重复出现，仅计一次，采用最近观测内容及点赞数。月报从月内所有快照独立去重，跨周事件不会被重复加权。

## 情绪与事件

评论产生 7 维相对情绪分数，归一化到总和约 100，再按 `1 + ln(1 + likes)` 加权平均。窗口总分是全部去重评论的加权平均；每个事件用对应评论独立求平均。因此评论更多的事件对总体影响更大，得分不是事件等权指数。

微博正文不参与民众情绪评分，只为摘要提供原文节选。相同事件 ID 的微博合并；未提供事件 ID 时保持独立。摘要不扩写原文事实，自动归纳/语义聚类尚未实现。

词典模型为可解释基线，没有准确率或置信度承诺。无情绪词命中表示中性/未识别，不代表作者实际中立。需要可靠语义分析时，可替换 `LexiconEmotionScorer.score(text)` 并记录新模型版本，用人工标注语料评估。

## 完整性状态

| 状态 | 含义 |
| --- | --- |
| no_data | 没有采样快照 |
| in_progress | 周期未结束，展示月内累计 |
| partial | 周期结束但缺日期或不足 30×100 目标 |
| complete | 周期结束，所有日期及 30×100 目标齐全 |

数据源返回空快照时表示当天获取到 0 条微博，不等同于未返回该日期。某事件没有评论时，其情绪显示“暂无评论数据”，不会判为中性。演示数据始终有独立标记和归档路径。

## 发布

每周一生成上一自然周与当月累计；每月 1 日生成上月报告。一次更新也重算所输入快照涉及的其他已结束周/月，已归档而未涉及的周期保留。README 只更新自动生成标记区，不覆盖手写介绍。

Markdown 与 JSON 报告一起归档，JSON 包含模型版本、窗口、覆盖率、事件摘要及分项得分。原始评论和评论标识不写入公开报告。
